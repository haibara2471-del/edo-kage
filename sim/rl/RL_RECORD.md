## 演化历史

### v0.42（胜利导向 + 存活工资 bug）
击杀 +100 / 承伤 0.1（残血放大）/ 时间 **+0.05×frames（符号反，=每步 +0.2 存活工资）**。
**结果**：EV 0.9+ "假健康"，蹲到 timeout 净赚 +180，胜率 0%。——时间惩罚符号 bug（v0.35 修过，v0.42 重写 reward 复发）。

### v0.43（修符号 + 击杀反通胀 + 承伤回落）
时间 → -0.05/frame（-0.2/步）；击杀 +100→+50；承伤 0.1→0.05。训练=random/测试=waves 纪律恢复。
**结果**：单足轻/对空 100%，足轻×3 → 边退边镖 timeout。根因：击杀 +50 尖峰压灭 dense。

### v0.44（数值经济重排）
击杀 +50→+15；承伤 0.05→0.03；时间 -0.2→-0.4/步。
**结果**：行为翻转"冲进敌群换血"——承伤 0.03 让换血无成本，无避伤梯度。

### v0.44b（避伤梯度，承伤是主杠杆）
承伤 0.03→**0.15**（5×，去残血放大）。**基础战斗全部毕业**：足轻×3 100%、弓+钩 100%、wave2 70%。但完整三波卡"推进触发下一波"（清完 wave1 停在 x=98 发呆）。

### v0.45 → v0.45c（advance 推进机制——三连失败，已定位）
推进奖励右移 +0.15/px；random 掺推进分支（25%/15%）。三个变体（maxTicks 4800/4800/3000）**全部崩基础战斗**，但 v0.45c waves 能打到 wave2（advance 机制可学）。
**根因假设（后被 v0.46 obs 修复证实）**：obs 敌人槽位 8/7 维漂移污染观察空间，advance 特征位置随敌数漂移。

### v0.46 obs 漂移修复（敌人槽位 8/7 维）
env.ts + ai.ts 空槽 `push(7个0)` → `push(8个0)`，尾部特征位置固定。
**结果**：战斗基础全面恢复且超越（wave2 20%→90%），但 waves 清场后"主动接近"短板暴露（开局全远敌不 aggro，模型站桩）。

### v0.46a-e 统一目标追踪 reward 演化
引入统一追踪（战斗期目标=最近敌人，推进期=路标），K 演化：
- **0.03**：走近 355px=+10.7≈击杀 15，追踪主导 → 弓+钩崩（钩使 73px 已"到位"，攻击 spam 卡死）
- **0.005**：弓+钩恢复 100%，Boss 0→70%；但推进段 +1.3 被时间惩罚淹没 → 清场后往左/徘徊
- **0.02**：弓钩保持，Boss 70%，推进"走 154px 半途"
- **双档 0.01/0.1**（σ=5.5 采样校准）：战斗期 0.17σ（安全指引）+ 推进期 3.4σ（走到底）。**战斗全毕业**（单足轻/足轻×3/弓钩/对空/wave2 全 100%，Boss 单 80% 历史最高）
**核心教训**：追踪 reward 是"苍蝇肉"（方向指引），大了会主导策略；推进段无战斗收益兜底，只能靠更大系数。

### 攻击判定 bug 修复（src/player.ts）
facing=-1 时玩家与敌人贴边完全重叠，`rectsOverlap` 严格 `>` 判 `0>0=false` → 墙角反复攻击打不死残敌。修复：hitbox 右缘 +1px。
**结果**：waves 从"全程卡死"（卡住帧 4734）变"能清场能推进"（卡住帧 360），**首次破零 10%**。

### 路标随机化
路标距离固定 260 → 随机 300~800（对齐真局 400-900 推进，防模型过拟合"走固定距离"）。

### v0.46i 课程重构（推进掺杂各分支，不再独立）
之前推进是独立 15% 分支，模型只在那结构见过推进。重构：每局抽战斗场景 C + 随机推进模式（纯战斗 50% / 后置推进 25% / 前置推进 25% 开局无敌人教"找战斗"）。
**修正 bug**：reset 尾部 `advanceTarget=-1` 覆盖前置推进路标 → 移到 reset 开头。

### v0.46k 多目标混合对空（解决"混合场景忽略乌鸦"）
回放证据：模型会打纯乌鸦（shurikenOnly 100%），但 air/wave2 混合场景把乌鸦当低优先级忽略 → 被磨死。撤销纯对空组（无用），改**多目标混合对空 25%**（2乌鸦+蝙蝠+2足轻）。**air 80%→100%**。

### 游戏版本适配（v0.48 → v0.51）
游戏窗口连续更新战斗机制，RL 每次重训适配：
- **v0.48** 普攻后摇可打断（player.ts）
- **v0.49** 平推与 Boss 角落修复
- **v0.50** 击飞连招平推修复——**起身免疫 40 帧 + 前摇纯霸体**（enemy/hook 提交信息明确"RL 交接：用真实 Enemy/HookSoldier，起身免疫+纯霸体改变"）。**与"残血打不死"直接相关**（免疫期攻击不打断）
- **v0.51** 钩子拉拽不再漂移 + 普攻击退削弱

### 训练方差（当前核心障碍）
**单次 300k 训练同配置结果天差地别**：v0.51 同配置两轮，wave2 90% vs 20%、waves 0% vs 10%。任何参数/课程改动都被方差淹没，无法可靠评估。
**对策**：2M 延长训练（收敛更充分，方差下降）。

### 🔴 评估工具 bug（推翻吸血归因）——waves 原地跳是假象

**根因**：`src/ai.ts buildObs()` 把 advance 特征硬编码 `-1`（浏览器端无路标），ai-replay/ai-analyze 直接复用 → **评估时模型永远看不到路标信号**（训练 env.ts:618 填真实路标距离）。

**证据**：修复前 waves 0/10 全 timeout 原地跳（idle=4677 一致）；修复后（buildObs 加可选参数传真实 advance）waves **1/10 胜 + 9/10 推进到 x=1400~2100**（wave2/wave3 战死，卡住帧 0-10，死亡全是正常战斗死因）。

**结论（推翻 v0.51 吸血归因）**：
- 吸血 reward 从头到尾与 waves 崩**无关**——"全原地跳 4677"是评估工具没传路标的假象，回滚后重训 2M 依旧"崩"因为工具一直没修
- 模型**推进其实学会了**（修复后能连续推进多段 1000+px）
- 真正的剩余问题：**wave2/wave3 长周期混战强度**——单局 wave2 10/10，但完整三波连续作战累加掉血 + wave3 新增 bruiser/shaman，模型在长周期混合波次战死
- 教训：评估结果不符合预期时，先 diff 评估工具 obs vs env.ts observe()（见 [[rl-eval-obs-fidelity]]）

### v0.52 吸血 reward 重测——冷启动解法 + waves 9/10 突破

**背景**：v0.51 吸血 reward 被评估 bug 假象误导回滚。修复评估工具后重测，发现吸血使用仍=0——**冷启动陷阱**：reward 只在"吸血 buff 激活+造成伤害"时给，但模型从不按吸血键 → heal 恒 0 → vampReward 恒 0 → reward 从没教过吸血。加"按吸血键"的 reward 是错的，得先引导探索动作本身。

**历史勘误**："AI 曾自动学会吸血"是**动作 index 错位**的误读——早期（8/3-8/4）动作表 index 10=左攻（非吸血），vamp 是后来才放进 index 10。用现在动作表解析历史 JSON 的 actionCounts['10'] 会误判。vamp 从头到尾从未被学会过（见 [[rl-vamp-never-learned]]）。

**解法（v0.52b）**：
1. **吸血启动奖励**：非满血按吸血键给 +3（`VAMP_ACTIVATE_REWARD`），引导探索动作本身；满血按无收益，仍学"低血才开"
2. **obs 加 vampCd/vampTimer 特征**：用尾部 2 个 padding 空位（42 维不变），模型感知 CD/buff 状态

**结果（50万步）**：
- 吸血使用：waves 87 次、wave2 27 次（从 0 破冰）
- **waves 1/10 → 9/10**！足轻×3 恢复 10/10（上轮 0% 是方差）
- 回放验证：低血（hp=44）才开、cd=0/ki≥20 条件满足、CD 期间不按转好续——行为正确
- 清场残血活着（hp=38-77），不再血线耗干

**预算**：吸血一次=回血40×0.1(+4)+启动+3；wave2 开1-2次占收入 3-6%（可控）。
